Notto 1.7.3

Fixed
• Closing a note is smooth now.
  Cards used to fly in from the top-left corner and overlap whenever the home
  grid was rebuilt. A freshly built grid is now positioned in the same frame,
  so nothing moves that shouldn't.
• The grid is no longer rebuilt in the middle of the close animation — it waits
  for the animation to finish, and is skipped completely if the note is unchanged.

Improved
• Cards use CSS layout containment, so re-laying out the grid costs less.
